*Лабораторные работы по предмету Технология разработки ПО*

В репозитории три папки:
- json, с двумя проектам: console и Avalonia, демонстрирующие сериализацию и парсинг json соответственно
- OAuth/GitHubOAuth2, демонстрирующие авторизацию через GitHub аккаунт благодаря OAuth.
- webapi с демонстрацией базового dotnet WebAPI. Реализовано:
   - AccessToken (15 минут) и RefreshToken (20 дней). AccessToken используется для аутентификации и посылается в заголовках запроса, RefreshToken для обновления обоих, посылается в теле запроса по истечении 15 минут, либо спустя время, когда пользователь решил зайти в систему. Больше 20 дней - RefreshToken недействителен - пользователь обязан повторно авторизоваться в систему.
   - C, R, и D задач пользователя
   - SQL-скрипт с исходной базой данных
